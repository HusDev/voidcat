# Voidcat — Hussein's decisions

Every product, design and working decision Hussein made, with the date. When he makes or changes a decision, edit the line here in place and add an entry to the change log at the bottom, in the same turn.

## Product
- **What it is:** smart storage for your life's documents. Drop anything in; it's read on your Mac, filed, and its facts extracted. Any AI can use that knowledge without seeing your private data.
- **Logo: the box cat** (his pick of four options, 18 Oct 2026: "Go with c"): a closed box with ears (storage) and the two slanted, watchful gold eyes (gold kept over cyan on 18 Oct 2026: cyan read as a robot cat, and cyan stays reserved for masked values); replaces the open line cat in the app, the app and menu-bar icons, the website and the video. Source: `src/components/Logo.tsx`, `src-tauri/icons/voidcat-icon.svg`, `tray.svg`.
- **Landing page (voidcat.io):** for real users (people whose paperwork spans countries); judges see that. Designed with the Impeccable skill (product record in PRODUCT.md). Fixed brand: the name and the cat logo only. Primary action: **Download for Mac** (an unsigned .dmg for Apple silicon hosted on voidcat.io, with the one-time "Open anyway" step), never a link to the GitLab page. Price line: the Mac app is free and open source, Voidcat Cloud is free while in beta.
- **Domain: voidcat.io** (he bought it at Namecheap, 18 Oct 2026): voidcat.io = a landing page, app.voidcat.io = Voidcat Cloud in a browser; www redirects to voidcat.io. The old run.app address keeps working.
- **Name:** **Voidcat**, final (decided 17 Oct 2026: "Voidcat is the final name"). Renamed from SafeBox on 12 Oct 2026, everywhere in the app. Earlier: "SafeBox" for now (other apps already use it); considered SafeDrop, SafeX, SafeXY, DocDrop, LifeBox.
- **Tagline (200 characters):** "SafeBox is smart storage for your life: drop in any document, it organises it and extracts the facts, and any AI can use your knowledge without ever seeing your private data."
- **Target users first:** people whose paperwork spans countries (immigrants, expats, international workers); later everyone.
- **A separate project from Hus:** Hus stays the private second brain; Voidcat is the product. No Hus personal data in its repo.
- **Any AI can connect:** like opencode's many connectors. Models go in through OpenRouter, and other apps come in through an MCP server (planned).
- **Amounts stay visible to the AI** ("amounts are kept"), including approved facts such as rent or a deposit, so it can reason about money.
- **Privacy is the core promise:** the library stays on the Mac; personal details are masked before any AI sees them; OpenAI's privacy-filter model is planned on top of the rules.

## Platform and stack
- **A desktop app,** not a web app (Tauri 2), so "stored on this Mac" is true. A phone version comes later, through the Mac or encrypted sync.
- **Stack:** his hus-stack (TypeScript, Bun, Vite, React, React Router, Tailwind v4, Zod, oxlint, Vitest), with **Headless UI** for components (his choice over Base UI) and Lucide icons.
- **Cloud models through OpenRouter** (his choice over the Vercel AI SDK alone, after checking the research). Every request uses zero data retention and no data collection. One key for all models, stored in the macOS Keychain. His own Anthropic/OpenAI keys are an advanced option.
- **Default cloud model: Claude Sonnet 5.5** (he asked Claude to choose). `:batch` models are hidden.
- **Local model (Ollama, qwen3.5:9b)** does reading, filing and fact extraction, so documents never go to the cloud before masking.
- **OCR:** Apple's on-device text recognition (Spanish, English, Arabic).

  - shows **what will be sent** and asks to review only when something private would leave; every answer keeps "What was sent" and its sources.
  - **chat history** in a column on the left, newest message first (opening a chat doesn't move it; a new message does): every conversation is saved on this Mac, you can go back to one and carry on, start a New chat, or delete one (a second click confirms);
  - a **model dropdown** in the header: models on this Mac (Ollama, real values, nothing leaves the computer) or the cloud model (masked). A provider that isn't set up shows as a disabled option saying "add model provider", with a link to Connected AIs.
- **Hide private details** (his idea, for screen recording): one switch, ⌘⇧H, that shows the AI's placeholders instead of real values everywhere and blurs source pages. Short forms of an address ("Robles 214") must be hidden too. It also hides, **on screen only**, nationality, country, place of birth, issuing place, sex and his first name, shown as [HIDDEN] (17 Oct 2026, seen in a passport answer); the AI still gets those readable because things like visa rules need them.
- **Writing documents in Voidcat** (19 Oct 2026, a grill-me session, all answers his): create and edit **Markdown (.md) and plain text (.txt)**; Word only as an **export** (.docx), never edited in place. The editor shows formatting as you type (MDXEditor); text files get a plain text area. **New document** in the Library header (▾ for Plain text; no dialog, "Untitled.md" opens with its name ready to type) and **New document here** in a sidebar folder's right-click menu. **Autosave** about 1.5 s after typing stops, plus ⌘S, with "Saved" under the title. Every .md/.txt can be edited (imported ones too) behind an **Edit** button; view stays the default. Search updates on every save; the local model runs **only when he asks** ("Find facts & file", his words: "you can do it manually, like fact check button"); a folder he chose stays. Notes may have the same text as another (the no-duplicates rule is for dropped-in files). **One previous version** is kept per editing session ("Restore previous version", again to undo). **Export** menu: Word (.docx) or the file as is. Hide private details blurs a note and disables Edit. **Mac only** for now: a browser shows notes read-only ("Edit on your Mac"). **Delete** in a note's tab (asks once), and a note closed while still empty and "Untitled" is removed by itself (19 Oct 2026, "do both").
- **Document tools (direction, 19 Oct 2026; designs https://claude.ai/artifact/CmA5r6XdNkNGtCKnuxUHs4):** the end goal is docs, sheets, converting between types and signing. Tools live in three places together: a tool row on every open document (**Sign · Pages · Convert ▾ · Redact**, beside Facts and Ask), a **+ New** menu at the top of the sidebar (Document, Sheet, Scan to PDF, Combine PDFs), and a **Tools** screen in the sidebar under Library (his words: "i like the tools tab can you keep it") with Write tools (New document, New sheet, Fill a form) and PDF tools (Sign, Combine, Split or reorder, Scan to PDF, Redact, Convert). Results are new documents; originals stay. Order (he agreed, "looks good"): visible signing, PDF tools + scan, convert, forms + redact, editable sheets.
- **Signing** (19 Oct 2026, grill-me session, all recommendations taken): a **visible signature** first; FNMT/DNIe digital signing (PAdES) later as its own step. Draw, Type or Upload (photo, background removed); kept once on this Mac, encrypted, "Forget my signature" in Settings. Voidcat **finds the spot** from the "sign here" words (the Unsigned label's), you drag to adjust or click anywhere; several spots allowed. Saving makes a **new PDF "<title> (signed)"** next to the original (original kept and linked; the signature flattened into the page; the copy has no Unsigned label). Signs PDFs, photos/scans (made a one-page PDF first) and Markdown notes (made a PDF first); Word after Convert exists. Extras: today's date (on by default) and text boxes (place, printed name, ticks) with approved facts offered. **Mac only**; the saved signature never goes to an AI or to the cloud on its own (only inside signed PDFs you keep there); Hide private details blurs it.
- **Library at scale** (19 Oct 2026; his words: "if i have soo many files will be so much to handle"; designs https://claude.ai/artifact/QGUqYmLv6UKHQQhUqfmDYa, he chose A + C, "go build it"): view tabs across the top (Needs you, Recently added, Expiring soon, Unsigned, Notes I wrote, Everything) and one compact list grouped by when files were added, each row with its folder and a key fact; filters (Area, Type, Year, Label), sort, List or Cards. Needs you holds every task as short rows (to file, facts to check, possible copies). The big drop zone and the long sections are gone: drop files anywhere, or Add files.
- **Calendar** (his idea):
  - every deadline and date becomes a reminder, including appointments such as the empadronamiento, with a "papers to bring" checklist;

  - Mac notifications and export to Apple/Google Calendar.
- **Other apps through MCP** (built): Claude Desktop, Cursor and Claude Code can use the library, always masked. Each app starts with **masked facts and dates only**; searching and reading pages must be allowed per app in Connected AIs, and any app can be turned off. SafeBox adds itself to Claude Desktop or Cursor with one click. ChatGPT is left out for now because it only connects to internet servers and the library stays on the Mac.
- **Contacts tab** (requested, built 12 Oct 2026; since 17 Oct 2026 **only those with an email or phone number**, or edited by hand — the others looked like random info): people and organisations in the documents (landlord, employer, lawyer, offices, bank, doctor) with role, phone, email, address and the documents they appear in; found by the local model; merged by name/email; masked as [PERSON_n] for AIs.
- **"Me" tab** (requested; name "Me" picked by Claude when asked to choose; built 12 Oct 2026): a profile built from all documents (identity and IDs, residency, home, work and money, education, health), each value with its source; a "Needs you" box for conflicts and missing details; a life timeline.
- **Opportunities tab** (his idea, from Hus): advantages and opportunities based on your situation, with Keep / Add to calendar / Done / Dismiss. Built as phase 3: the scan sends only masked facts and document names, shows what will be sent first, and web checking is optional and off by default because it falls outside zero data retention. Dismissed ideas never come back.
