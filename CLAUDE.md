# Voidcat — project notes

**Start here:** read `PREFERENCES.md` (every decision Hussein made, with dates) and `docs/STATUS.md` (what's built, what's next, gotchas), then this map. Whenever he makes or changes a decision, update `PREFERENCES.md` in the same turn: edit the line and add a dated change-log entry.

Desktop app (Tauri 2) for smart personal document storage: drop files in, they are read locally, filed, and facts are extracted into an approval inbox. Any AI can use the library through masked context (privacy filter + reversible placeholders) or an MCP server. Separate from Hus (Hussein's private app): never copy Hus's personal data into the repo (tests and designs use made-up data). The same goes for the real contents of the Voidcat library: never use real addresses, names, amounts or IDs from it in code, tests, comments, prompts or designs; invent them.

Decisions:
- Desktop first (Tauri 2), data stays on the Mac.
- Models through the Vercel AI SDK with the OpenRouter provider; every request sets `zdr: true` and prompt logging stays off. Users may add their own Anthropic/OpenAI key; Ollama for local.
- UI: the Voidcat look (rebrand, 12 Oct 2026; first called SafeBox. `src-tauri/src/legacy.rs` moves the old `dev.hus.safebox` folder and `safebox.db` on start; `secrets.rs` moves the Keychain key from service `dev.hus.safebox`; `apps::sync_entry` swaps an old `safebox` MCP entry for `voidcat` and repoints it when the server path changes. The repo is the hackathon Showcase project (remote `showcase`; private copy gitlab.com/hus.dev/voidcat, remote `origin`) and the folder ~/lab/voidcat). Theme tokens in `src/index.css` `@theme` (light) with dark values under `prefers-color-scheme: dark` (unless `data-theme="light"`) and again under `:root[data-theme="dark"]`; `src/lib/theme.ts` (`useTheme`, localStorage `voidcat.theme`, applied in `main.tsx` before the first paint) sets `data-theme` from Settings → Appearance (`src/routes/Settings.tsx`, route `/settings`); the rail tokens are the same in both (sidebar always dark). Map:
- Storage (Rust, `src-tauri/src/store.rs`): SQLite `voidcat.db` + `files/` in the app data folder (`~/Library/Application Support/dev.hus.voidcat/`). - Reading + facts (step 2): `src/lib/pipeline.ts` queues documents → `reader.ts` (unpdf for PDF text; photos and scanned PDF pages read by Apple Vision on-device OCR in `src-tauri/src/ocr.rs` — commands `ocr_document`, `ocr_image` with raw PNG bytes; scanned PDF pages rendered with pdf.js on an OffscreenCanvas at 2×, max 40 pages; spreadsheets .xlsx/.xls/.ods read in Rust by `calamine` in `src-tauri/src/sheets.rs` (command `read_sheets`, max 2000 rows a sheet, dates as YYYY-MM-DD; fixture `src-tauri/testdata/sample.xlsx`), one page per sheet, method `sheet`, shown as a table in the viewer; text files and .csv directly; Word .docx read in Rust (`src-tauri/src/docx.rs`, command `read_docx`: `<w:t>` runs, paragraphs, table cells " | ", pages split at page breaks); `migrate` fills in `mime` for files added before their type was known; a name without a known extension gets its type from the first bytes (`sniff`: PDF, PNG, JPEG, WebP, HEIC), on import and for stored ones on start (`fill_types`, which marks them to be read again)) → `save_reading` into FTS5 `pages` → `extract.ts` files it with a LOCAL model (Ollama `qwen3.5:9b`, JSON-schema output, values copied verbatim so the source page can highlight them) → `save_filing` (title, area, doc_type, pending facts). Inbox = real pending facts with the source page; approve / reject / correct. Library search = FTS5 inside pages (`search`, snippets with [[ ]]). Cloud models only after the privacy filter. CSP allows `http://localhost:11434` only.
- Privacy layer (`src/lib/privacy.ts`, tests in `privacy.test.ts`): `Masker` masks approved fact values first (kind from the label), then patterns (email, IBAN, NIE/DNI, passport/card numbers, dates in ES/EN formats, phones ≥9 digits); amounts are kept. Reversible placeholders `[KIND_n]` numbered in reading order; dates get a relative note ("about 5 months from now"). Approved facts that are amounts ("2.300 euros", "€1,150 / month") are kept, like amounts in text. `unmask` also accepts placeholders without brackets.

Encryption (17 Oct 2026, `src-tauri/src/vault.rs`): a random master key in the Keychain (service `dev.hus.voidcat`, item `library-key`, never exposed to the interface; `secrets.rs` NAMES stays `openrouter` only); SHA-256 derives the SQLCipher key (`rusqlite` feature `bundled-sqlcipher`, CommonCrypto on macOS, OpenSSL in CI) and the files key (AES-256-GCM, file = `VCAT\x01\x00` + 12-byte nonce + ciphertext). `Store::open(dir, vault)` converts a plain library once (`open_encrypted`: `sqlcipher_export`, row counts compared, then swapped; `encrypt_files` checks each file's sha256 before replacing it); a new key is never made for an already-encrypted database. Read files only through `bytes_of` / `contents_of`; "Open in default app" writes a decrypted copy to `opened/` (emptied on start). The MCP server can't open the database: the app serves it over `mcp.sock` in the library folder (0600, `src-tauri/src/mcp_bridge.rs`: hello/level, snapshot, search, page), so MCP works only while Voidcat runs. A Keychain refusal shows a dialog and quits; a missing key on an encrypted library (`vault::Load::Missing`) manages `Locked(dir)` instead of the store, and `main.tsx` renders only `routes/Recover.tsx` (`library_locked`, `recover_library`: `Store::opens` checks the code, `Vault::save`, `app.restart()`). Recovery key = the master key in RFC 4648 base32, 13 groups of four (`recovery_code`, forgiving 0/O, 1/I, 8/B); shown in Settings → Your data, which also has **Export everything** (`export_all`: every document decrypted, named `Area/Folder/file`, through `bundle::write`). It's fine to say the library is encrypted.
