# Voidcat — project notes

**Start here:** read `PREFERENCES.md` (every decision Hussein made, with dates) and `docs/STATUS.md` (what's built, what's next, gotchas), then this map. Whenever he makes or changes a decision, update `PREFERENCES.md` in the same turn: edit the line and add a dated change-log entry.

Desktop app (Tauri 2) for smart personal document storage: drop files in, they are read locally, filed, and facts are extracted into an approval inbox. Any AI can use the library through masked context (privacy filter + reversible placeholders) or an MCP server. Separate from Hus (Hussein's private app): never copy Hus's personal data into the repo (tests and designs use made-up data). The same goes for the real contents of the Voidcat library: never use real addresses, names, amounts or IDs from it in code, tests, comments, prompts or designs; invent them.

Decisions:
- Desktop first (Tauri 2), data stays on the Mac.
- Models through the Vercel AI SDK with the OpenRouter provider; every request sets `zdr: true` and prompt logging stays off. Users may add their own Anthropic/OpenAI key; Ollama for local.
- UI: the Voidcat look (rebrand, 12 Oct 2026; first called SafeBox. `src-tauri/src/legacy.rs` moves the old `dev.hus.safebox` folder and `safebox.db` on start; `secrets.rs` moves the Keychain key from service `dev.hus.safebox`; `apps::sync_entry` swaps an old `safebox` MCP entry for `voidcat` and repoints it when the server path changes. The repo is the hackathon Showcase project (remote `showcase`; private copy gitlab.com/hus.dev/voidcat, remote `origin`) and the folder ~/lab/voidcat). Theme tokens in `src/index.css` `@theme` (light) with dark values under `prefers-color-scheme: dark` (unless `data-theme="light"`) and again under `:root[data-theme="dark"]`; `src/lib/theme.ts` (`useTheme`, localStorage `voidcat.theme`, applied in `main.tsx` before the first paint) sets `data-theme` from Settings → Appearance (`src/routes/Settings.tsx`, route `/settings`); the rail tokens are the same in both (sidebar always dark). Primary actions `bg-accent` (never `bg-ink`, which is text colour and flips in dark); private = cyan tokens (`private*`, `chip`; amber was dropped); `text-[#0b0b0f]` only for text on the cyan fill. Map:
- Storage (Rust, `src-tauri/src/store.rs`): SQLite `voidcat.db` + `files/` in the app data folder (`~/Library/Application Support/dev.hus.voidcat/`). Tables `documents` (sha256 unique = no duplicates, status new/read/filed), `facts` (pending/approved/rejected), FTS5 `pages` (accent-insensitive). Commands in `lib.rs`: `import_files`, `list_documents`, `library_stats`, `open_document`, `remove_document`; TS wrappers in `src/lib/library.ts` (`hasLibrary` false in the browser preview). Drops come from Tauri's `onDragDropEvent` (gives paths); the picker is `@tauri-apps/plugin-dialog`. Rust tests: `cargo test` in `src-tauri`.
- Reading + facts (step 2): `src/lib/pipeline.ts` queues documents → `reader.ts` (unpdf for PDF text; photos and scanned PDF pages read by Apple Vision on-device OCR in `src-tauri/src/ocr.rs` — commands `ocr_document`, `ocr_image` with raw PNG bytes; scanned PDF pages rendered with pdf.js on an OffscreenCanvas at 2×, max 40 pages; text files directly) → `save_reading` into FTS5 `pages` → `extract.ts` files it with a LOCAL model (Ollama `qwen3.5:9b`, JSON-schema output, values copied verbatim so the source page can highlight them) → `save_filing` (title, area, doc_type, pending facts). Inbox = real pending facts with the source page; approve / reject / correct. Library search = FTS5 inside pages (`search`, snippets with [[ ]]). Cloud models only after the privacy filter. CSP allows `http://localhost:11434` only.
- Privacy layer (`src/lib/privacy.ts`, tests in `privacy.test.ts`): `Masker` masks approved fact values first (kind from the label), then patterns (email, IBAN, NIE/DNI, passport/card numbers, dates in ES/EN formats, phones ≥9 digits); amounts are kept. Reversible placeholders `[KIND_n]` numbered in reading order; dates get a relative note ("about 5 months from now"). Approved facts that are amounts ("2.300 euros", "€1,150 / month") are kept, like amounts in text. `unmask` also accepts placeholders without brackets.
- Cloud (`src/lib/cloud.ts`): Vercel AI SDK + `@openrouter/ai-sdk-provider`, every model created with `provider: { zdr: true, data_collection: "deny" }`. Key in the macOS Keychain (`src-tauri/src/secrets.rs`, keyring v3, only name `openrouter`); chosen model id in localStorage. Model list from the public `/api/v1/models`.
- Ask (`src/routes/Ask.tsx`): question → any-word FTS search (top 5 pages) + approved facts → masked prompt shown in full before sending → streamed answer unmasked locally, with sources. Connected AIs = OpenRouter card (key, model combobox; `:batch` models hidden; default `anthropic/claude-sonnet-5.5`) + Ollama status + the MCP card. Privacy `variants()` also masks short forms of approved addresses/names with the same placeholder.
- Hide private details (`src/lib/veil.tsx`): `VeilProvider` (state in localStorage `voidcat.veil`, toggle ⌘⇧H or the sidebar eye) with one app-wide `Masker` built from approved facts. `<Private>` shows a value as its placeholder chips while on; `<Blurred>` blurs long free text (source pages). Ask stores each answer's raw (masked) text and shows it while on. Apply `<Private>` to any new personal value shown in the UI.
- Folders (phase 1): two levels, area › folder. Table `folders` (unique area+name, case-insensitive lookups in code); `documents.folder_id`, `filing` (auto | suggested | confirmed), `suggested_area/folder`, `suggestion_reason`. The local model gets the folder list (`folderList`) and returns folder, folderExists, confidence, reason; `folderName()` keeps two levels. `save_filing` files automatically only when the folder exists and confidence is high; otherwise the document waits in the Library's "to file" strip (`components/ToFile.tsx`). `FolderPicker` (Headless UI Combobox) for Other folder / Move. Sidebar folder tree links to `/?folder=<id>`; Library filters by it. "Suggest folders" re-runs the pipeline for documents filed before folders existed.
- Calendar (phase 2): `src/lib/calendar.ts` (pure, tested in `calendar.test.ts`): `eventsFromFacts` turns approved DATE facts into events by label (`dateKind`: issued/birth/signed = history, skipped; valid/expires; appointment/cita; deadline/due; end; start), works out renewals 60 days before expiry of IDs/permits (`renew:<fact>`) and the next two monthly payments from texts like "del 1 al 5 de cada mes" (`monthlyDueDay`, `pay:<fact>:<yyyy-mm>`); appointment time/place from facts of the same document. Stored in Rust (`src-tauri/src/calendar.rs`): manual `events`, `events_done` (by key), `event_papers` (by key), `reminders_sent`. `REMINDERS` per kind; `dueReminders` picks only the latest passed reminder per event; `useReminders` (App) checks every minute and sends Mac notifications via `@tauri-apps/plugin-notification`, claiming each key once. `toIcs` export (stable UIDs, VALARMs) saved through the dialog + `save_calendar_file` (.ics only). Papers checklist: `papersToBring` (local model) + `matchPaper` to library documents. Route `/calendar`; sidebar badge = appointments/deadlines/expiries within 14 days.
- Opportunities (phase 3): `src/lib/opportunities.ts` (tested in `opportunities.test.ts`): `buildScan` = approved facts + document list (D1… numbers, title, folder, type; never page text) + known ideas, masked with a fresh `Masker`; `scanCloud` = `generateText` + `Output.object(Found)` through OpenRouter with ZDR, optional web plugin (`plugins: [{ id: "web" }]`, not covered by ZDR, off by default, remembered in localStorage `voidcat.scanWeb`); `restore` unmasks, normalises keys, turns D-numbers into `doc:<id>` sources, keeps only https links, and gets `deadlineDate` from the unmasked deadline. Stored in `src-tauri/src/opportunities.rs` (`opportunities` table keyed by the model's key; a rescan updates text but keeps status; dismissed rows are never updated). Commands `list_opportunities`, `save_opportunities`, `set_opportunity_status`. Screen `/opportunities`: review panel (what will be sent, web toggle, cost estimate from the model's price), area tabs, cards with Keep / Add to calendar (manual `deadline` event, asks for a date if none) / Done / Dismiss, folded "Checked, not for you", Done, Dismissed (Bring back).
- MCP server: `mcp/server.ts` (Bun, `@modelcontextprotocol/sdk`, stdio) reads `voidcat.db` with `bun:sqlite` (`VOIDCAT_DIR` overrides the folder) and answers through `VoidcatTools` in `src/lib/mcp.ts` (tested in `mcp.test.ts`), which masks every output with a `Masker` built from approved facts and appends date notes for the placeholders used. Tools: `list_documents`, `get_facts`, `upcoming_dates` (level facts) and `search_documents`, `read_page` (level search). Each call reads the caller's level fresh from `ai_apps` (keyed by the MCP clientInfo name; new apps get `facts`) and counts the call. `bun run build:mcp` compiles it to `src-tauri/binaries/voidcat-mcp-<triple>` (gitignored; `externalBin`, so it sits next to the app's executable; built by before-dev/build commands, and needed before `cargo test`). `src-tauri/src/apps.rs`: `ai_apps` levels, `server_path`, and `connect` writes/removes `mcpServers.voidcat` in Claude Desktop's or Cursor's JSON settings (keeps other keys, backup `*.json.voidcat-backup`). Connected AIs → "Other apps · MCP" card: apps with level selects, Add to Claude Desktop / Cursor, Claude Code command to copy. ChatGPT needs a remote server: not supported.
- Contacts and Me (`src/lib/people.ts`, tested in `people.test.ts`; Rust `src-tauri/src/people.rs`): `askLocal` (in `extract.ts`) is the shared Ollama JSON call. `findContacts` reads one document's people and organisations (owner names from contacts marked "This is me" are left out); `pipeline.ts` runs `scanContacts` after filing (failures don't fail the document); `contacts_scanned` tracks which documents were read, Contacts shows "Find contacts" for the rest (`scanAll`, progress via `useScanning`). Rust merges by email or by name words in any order, fills only empty fields, never touches contacts edited by hand (`edited`), skips `is_me`, hides `hidden`; `contact_mentions` (document + pages, cascade on document delete). `contactFacts` feeds people's name/phone/email/address/ID to every `Masker` (veil, Ask, Opportunities, MCP `privateValues`); organisations stay readable. Me: `buildProfile` sends approved facts as `F1 | label | value | document` to the local model (num_ctx 32768), which answers with fact ids only (owner name, grouped fields, conflicts, missing, timeline); ids are mapped back so every value shown is an approved fact. Saved as JSON in `profile` with `factCount` (stale banner when it changes); conflict choices in `profile_choices` keyed by label (lower case). Building also marks the contact matching the owner's name as "me". Routes `/me`, `/contacts`.
- `src/App.tsx` routes (HashRouter): `/` Library, `/me` Me, `/contacts` Contacts, `/ask` Ask, `/calendar` Calendar, `/opportunities` Opportunities, `/inbox` Facts to approve, `/connections` Connected AIs, `/settings` Settings.
- `src/components/Sidebar.tsx`, `Logo.tsx`; `src/routes/*`; `FolderPicker`, `ToFile`, `SourcePage`.
- `src-tauri/` Rust shell; window has an overlay title bar, drag regions use `data-tauri-drag-region` (permission `core:window:allow-start-dragging`).

Not encrypted yet (plan: SQLCipher); don't claim encryption in the UI until it is.

- CI (`.gitlab-ci.yml`): stages verify (`verify`, `rust-test` on Linux with Tauri's packages), secure (SAST, secret detection, dependency scanning templates), govern (`privacy-guard`), package (`mcp-server`: darwin arm64 + x64 binaries), release (`v*` tags: `publish-packages` to the generic registry, `release` with notes from that version's `CHANGELOG.md` section). Privacy guard: logic in `src/lib/guard.ts` (tested), command `scripts/privacy-guard.ts` (`bun run privacy`, `--all`, `--hash "value"`); invented test values go in `.privacy-allow`; real private words only as SHA-256 hashes in the `PRIVACY_WATCH` CI variable. It prints values redacted because job logs are public.

Commands: `bun run tauri dev`, `bun run build:mcp`, `bun run typecheck`, `bun run lint`, `bun run test`, `bun run build`, `bun run privacy`. Rust via `~/.cargo/bin`.
